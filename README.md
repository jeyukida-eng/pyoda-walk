# PYODA WALK

서귀포 골목 도슨트. 펴다워크 전용 저장소입니다.

- 모바일 화면에 맞춘 10개 마을 지도
- 등록된 좌표 근처에서 음성 도슨트 자동 시작
- 장소별 좌표 설정 및 내보내기
- PYODA WALK 전용 아이콘, 설치 정보, 서비스 워커 캐시

## 배포
GitHub Pages: main 브랜치 / (root).

## 현재 제한
실제 좌표는 보목포구 1개가 등록되어 있으며 나머지는 현장 등록이 필요합니다. 브라우저에서 화면 잠금 후 위치 추적과 음성 재생은 보장되지 않습니다. 안드로이드 백그라운드 서비스는 별도 소스 단계이며 APK 및 실기기 검증이 필요합니다.
